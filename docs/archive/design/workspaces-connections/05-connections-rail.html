Connection status icons
StatusWhat it meansClick or Enter
Not connectedNothing has been dialled. This is how every connection starts, so opening a workspace is instant.Expands and connects.
ConnectedAttached and answering.Expands.
Can't connectThe reason is shown under the row, with secrets removed. Never swallowed.Opens the editor on the Test result.
Needs credentialsNo saved sign-in on this computer yet, the keychain isn't reachable, or the server changed since you signed in (the sign-in is tied to the host, port and database). Sign in again to confirm.Opens the sign-in prompt.
Extension neededA one-time download is required for this type.Opens the install prompt.
In use by pid 4182Another Vibe process holds this local file (a people icon, so it isn't confused with the read-only padlock). Remote connections still work.Offers Take over.

If several apply, the row shows the first of: extension needed, needs credentials, can't connect, in use by another process, not connected, connected.
