Can't reach your keychain

You can still connect. Set PG_PROD_USER and PG_PROD_PASSWORD in the environment Vibe starts from, then choose Environment variables for this connection. Vibe never writes passwords to a file instead.

Install the httpfs extension?

To read files from S3, Google Cloud Storage or R2, Vibe's database engine needs a small add-on called the httpfs extension. It isn't included, so Vibe needs to download it once. (Postgres connections ask the same way for the postgres extension.)

  • Downloaded from extensions.duckdb.org.
  • Kept in Vibe's own folder, shared by all your workspaces. It won't touch any DuckDB you installed yourself.
  • Needed by 1 connection here: lake.
Offline? You can skip this and the connection will wait with an "Extension needed" icon.

Take over Acme Analytics?

Vibe will ask vibe mcp serve (pid 4182) to let go of this workspace, then open it for editing.

Claude Desktop or Claude Code sessions that were using it will reconnect through Vibe Studio. Nothing is deleted, and open notebooks aren't affected.

After you take over, any change Claude makes needs your approval in Vibe Studio, and closing Studio ends the session it was passing along.
